Explore the preview

The Windows build is in private review. This public demo includes fictional inputs, real text exports from the preview, and a user manual. The current preview supports UTF-8 text, Markdown, CSV, and TSV most directly. Its source and bank text limits are 64 MiB. Word and PDF extraction can depend on installed converters and may carry coverage holds.
